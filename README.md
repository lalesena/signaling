# Señales, de 0 a experto

Curso interactivo de procesamiento de señales del canal de YouTube **Ena en Curso**: 21 lecciones, de la noria al
sincrosqueezing, con retos, un laboratorio para analizar tu propia voz y exámenes.

Se ve en **https://lalesena.github.io/signaling/**. Es una web estática, sin servidor ni cuentas: el progreso de
cada alumno se guarda solo en su navegador.

Las fuentes (Literata e IBM Plex Mono) se sirven desde la propia web y tienen licencia SIL Open Font License 1.1
(`comun/fuentes/OFL-*.txt`). Las fórmulas se dibujan con KaTeX, que se carga desde cdnjs al abrir el rincón
matemático.
